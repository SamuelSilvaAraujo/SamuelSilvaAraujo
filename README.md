### 🚀 Projetos em Destaque

#### 🏢 Sistema Globaltec (ERP/CRM Sob Medida)
Um sistema completo desenvolvido para centralizar o fluxo de atendimento, gestão de ordens de serviço (OS) e agendamento de visitas técnicas.
- **Destaques:** Gestão de permissões de usuários (ACL), automação de ciclo de manutenções (retenção a cada 6 meses), conteinerização com Docker e gestão de dependências isoladas (pip-tools).
- **Stack:** Python, Django, PostgreSQL, JavaScript, Docker.
